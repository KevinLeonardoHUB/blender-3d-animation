# External asset notes

The original Blender production used third-party texture and audio files during development.

Those files are intentionally excluded from this public repository because their licences and redistribution terms have not been independently verified. This includes:

- bark, branch and rock textures;
- footsteps audio;
- a short sound-effect clip used during editing.

The included `.blend` file, screenshots, renders and presentation are provided as portfolio evidence of the project. If Blender reports a missing external file, replace it with an asset that you are licensed to use or relink your own local copy.
